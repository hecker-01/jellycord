Jellycord

Shows what people are watching on this server as their Discord status. Each user links their own Discord account; nobody needs the Discord desktop app running.

1. Discord application

Create an app at discord.com/developers/applications, turn on OAuth2 → Public Client, and fill in Discord Social SDK → Getting Started (self-serve). The app's name is not shown in the status; the media title is.

Only needed if Public Client is off. Never shown again once saved.

2. Artwork

Optional. Only set this if the server is reachable from the internet over HTTPS; Discord then loads posters straight from it. No API key is ever added to image URLs. Leave empty for LAN/Tailscale/VPN-only servers.
Without a public URL, Jellycord first uses the poster's original source (TMDB, MusicBrainz…) through your server's metadata providers. This option is a last resort for items with no online match: the poster is uploaded to Litterbox (catbox.moe) and deleted after 72 hours. It publishes your artwork to a third party, so it's off by default.
Used when no poster is available (e.g. no public URL): an https image URL or an art asset key from your Discord app. Leave empty for the Jellycord logo, or enter none for no image.
